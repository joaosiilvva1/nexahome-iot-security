# NexaSense — Avaliação de segurança IoT

Projeto acadêmico original para avaliação de segurança do dispositivo conceitual NexaSense, no cenário NexaHome.

- Site: [NexaSense — GitHub Pages](https://joaosiilvva1.github.io/nexahome-iot-security/)
- Materiais em HTML com navegação e layout responsivo: `docs/`
- Relatório técnico: `report/Relatorio-Tecnico-NexaHome.pdf`
- Fontes e registros em Markdown, demonstração local e anexos: diretórios temáticos do repositório.

O site principal encaminha para páginas HTML formatadas. Os arquivos Markdown permanecem como registros-fonte para consulta no repositório. O conteúdo separa hipóteses de achados confirmados: a equipe não recebeu placa, firmware nem captura de rede NexaSense. A simulação é estritamente local e usa dados sintéticos; portanto, não substitui evidências experimentais do produto nem um vídeo de ensaio físico.
