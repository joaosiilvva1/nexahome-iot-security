Demonstração local

O simulador didático ilustra duas propriedades: telemetria HTTP legível em um servidor local e um verificador fictício que aceita bytes alterados quando não confere assinatura.

Escopo: demonstração inteiramente em software, presa a 127.0.0.1 e com dados artificiais. O log é observação da aplicação local, não PCAP nem tráfego de um dispositivo.

Como executar

Requer apenas Python 3; não instala pacotes nem acessa a Internet. O servidor fica limitado a 127.0.0.1.

python demo/local_lab_simulation.py

SIM01 · HTTP local

O script envia valores sintéticos a um serviço temporário local. O log demonstra que o corpo JSON é visível na aplicação didática, sem TLS nem autenticação.

SIM02 · Atualização fictícia

O modelo inseguro aceita bytes modificados; uma verificação HMAC didática aceita a fixture original e rejeita a alteração. Nenhum firmware é escrito em hardware.

Hash de fixture sintética

O hash registrado é de bytes produzidos localmente para explicar preservação e integridade. Não é SHA-256 de firmware do produto.
