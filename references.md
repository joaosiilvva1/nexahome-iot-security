# Referências

1. Gao, Chao; Luo, Lan; Zhang, Yue; Pearson, Bryan; Fu, Xinwen. “Microcontroller Based IoT System Firmware Security: Case Studies.” IEEE ICII, 2019. Estudo de caso PurpleAir: UART/debug e atualização OTA sem autenticação/verificação no dispositivo estudado. É uma referência externa, não um achado sobre NexaSense. https://www.cs.uml.edu/~xinwenfu/paper/Conferences/19_ICII_MicrocontrollerBasedIoTSystemFirmwareSecurity-CaseStudies.pdf
2. OWASP. IoT Security Testing Guide (ISTG), teste de UART e interfaces internas. https://github.com/OWASP/owasp-istg/blob/main/src/03_test_cases/internal_interfaces/universal_asynchronous_receiver_transmitter.md
3. NIST. NISTIR 8259A, IoT Device Cybersecurity Capability Core Baseline, maio de 2020. https://csrc.nist.gov/pubs/ir/8259/a/final
4. ETSI. EN 303 645 V3.1.3, Cyber Security for Consumer Internet of Things: Baseline Requirements, setembro de 2024. https://www.etsi.org/deliver/etsi_en/303600_303699/303645/03.01.03_60/en_303645v030103p.pdf
5. MITRE. EMB3D Embedded Device Threat Model. https://emb3d.mitre.org/
6. Espressif. ESP-IDF Security Overview - ESP32. https://docs.espressif.com/projects/esp-idf/en/latest/esp32/security/security.html
7. Espressif. Flash Encryption - ESP32. https://docs.espressif.com/projects/esp-idf/en/stable/esp32/security/flash-encryption.html

A versão e a variante do microcontrolador devem ser confirmadas antes de aplicar recomendações específicas de plataforma.
